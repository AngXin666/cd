### 方案 A：快速测试（开发环境）

如果你想先在开发环境测试小程序功能：

1. **构建小程序**
   ```bash
   cd fleet-manager
   ./build-miniprogram.sh
   ```

2. **下载微信开发者工具**
   - 访问：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   - 下载并安装

3. **导入项目**
   - 打开微信开发者工具
   - 选择「导入项目」
   - 项目目录：`fleet-manager/frontend/dist/build/mp-weixin`
   - AppID：`wxf11a504cd3e01346`
   - 勾选「不校验合法域名」（开发时可以使用 HTTP）

4. **测试功能**
   - 使用测试账号登录
   - 测试各个功能模块

### 方案 B：正式发布（生产环境）

如果要正式发布给用户使用，需要配置 HTTPS：

#### 选项 1：当前服务器配置 HTTPS（需要域名）

**成本：** 域名费用约 50-100 元/年

**步骤：**
1. 购买域名（如：api.yourcompany.com）
2. 域名解析到服务器：45.197.148.64
3. 在服务器上安装 Nginx 和 SSL 证书
4. 配置反向代理

**优点：** 完全控制服务器
**缺点：** 需要购买域名，需要配置服务器

#### 选项 2：腾讯云 Serverless（推荐）

**成本：** 完全免费（30 个用户在免费额度内）

**步骤：**
1. 注册腾讯云账号
2. 部署 FastAPI 到 Serverless
3. 自动获得 HTTPS 域名
4. 数据库继续使用现有服务器（不需要迁移）

**优点：** 
- 完全免费
- 自动 HTTPS
- 无需管理服务器
- 自动扩缩容

**缺点：** 
- 需要适配代码（工作量约 1-2 小时）

## 常见问题

**Q: Android APP 的热更新还能用吗？**
A: 能！我们使用了条件编译，Android APP 保留热更新功能，小程序自动跳过。

**Q: 两个客户端会冲突吗？**
A: 不会，它们共用同一个后端，数据完全同步。

**Q: 现在就可以测试小程序吗？**
A: 可以！在开发环境中勾选「不校验合法域名」即可测试。

**Q: 什么时候需要 HTTPS？**
A: 只有正式发布时才需要。开发测试可以使用 HTTP。

**Q: 推荐哪个方案？**
A: 如果预算有限，推荐腾讯云 Serverless（完全免费）。如果想完全控制服务器，可以购买域名配置 HTTPS。

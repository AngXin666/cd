### Vue 版本新增功能

1. **图片预加载系统**：使用 `useImagePreloader` Hook 实现可视区域图片预加载
2. **滚动懒加载**：根据滚动位置计算可视区域，只预加载可见的图片
3. **后台预加载**：低优先级预加载即将显示的图片

### TSX 版本独有功能

1. **Realtime 订阅**：使用 `useRealtimeSubscription` 监听车辆审核状态变更
2. **实时通知**：收到审核结果时显示 Toast 通知

## 总结

### 关键发现

1. **技术栈完全不同**：备份点是 Taro + React (TSX)，当前项目是 UniApp + Vue 3
2. **功能基本一致**：核心功能（车辆列表、提车还车、审核状态）在两个版本中都已实现
3. **各有优势**：
   - TSX 版本有 Realtime 订阅功能
   - Vue 版本有图片预加载和滚动懒加载优化

### Vue 版本新增页面

- 司机端：`lease.vue`（租赁信息）、`supplement-photos.vue`（补录照片）
- 老板端：`lease-reminders.vue`（租金提醒）、`history.vue`（车辆历史）
- 车队长端：`list.vue`（车辆管理）- 全新角色

## 建议

1. **保留当前 Vue 版本**：功能更完善，有图片优化
2. **考虑补充 Realtime 功能**：将 TSX 版本的实时订阅功能移植到 Vue 版本
3. **车队长端是新功能**：TSX 版本没有车队长的车辆管理页面

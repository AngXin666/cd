## 修复记录

### 2025-12-24 修复内容

1. **车辆 API 500 错误**
   - 问题：`create_vehicle` 使用了 `crud.select` 而不是 `select`
   - 修复：改用 `from sqlmodel import select as sql_select`

2. **数据库表结构不匹配**
   - 问题：旧数据库缺少 `ownership_type` 等新字段
   - 修复：删除旧数据库，重新创建

3. **测试参数错误**
   - 问题：`leave_type: "事假"` 应为 `leave`
   - 问题：`status: "APPROVED"` 应为 `approved`/`active`
   - 修复：更新测试文件使用正确的枚举值

# 📦 归档目录

此目录用于存放历史文件、临时文件和已完成任务的相关文件。

## 📁 目录结构

```
archive/
├── apk/              # 历史APK文件（已删除，只保留最新版本在根目录）
├── sql/              # 历史SQL脚本（5个）
├── scripts/          # 临时修复脚本（12个）
├── docs-reports/     # 文档临时报告（40+个）
└── README.md         # 本文件
```

## 📋 文件说明

### sql/ - SQL脚本
存放已执行或临时的SQL脚本：
- `测试更新.sql` - H5更新测试脚本
- `修复h5_versions表.sql` - 表修复脚本
- `deploy-h5-v1.0.0.sql` - 旧版本部署脚本
- `EXECUTE_IN_DASHBOARD.sql` - Dashboard执行脚本
- `fix-notifications-rls.sql` - 通知RLS修复脚本

### scripts/ - 临时脚本
存放已完成任务的临时修复脚本：
- `fix_*.py` - Python修复脚本
- `fix_*.ps1` - PowerShell修复脚本
- `fix-*.js` - JavaScript修复脚本
- `clean_*.py` - 日志清理脚本
- `check_*.ps1` - 编码检查脚本

### docs-reports/ - 文档临时报告
存放已完成任务的临时报告文档：
- `代码质量修复-*.md` - 代码质量修复阶段报告
- `*测试*.md` - 各种测试报告
- `*完成报告*.md` - 任务完成报告
- `任务*.md` - 优化方案任务报告
- `今日工作总结*.md` - 工作总结
- 其他临时报告

**说明**：这些报告记录了项目开发过程中的各个阶段，已完成归档。重要的总结和指南已保留在"文档"文件夹中。

### apk/ - APK文件
**注意**：旧版本APK已删除，只保留最新版本在根目录。

## 📝 维护说明

### 何时添加文件到归档
- 已完成的临时任务脚本
- 已执行的SQL脚本
- 旧版本的APK文件
- 不再使用的配置文件

### 何时清理归档
- 每季度检查一次
- 删除超过6个月的临时文件
- 保留重要的历史记录

### 不应归档的文件
- 当前使用的配置文件
- 活跃的开发脚本
- 最新版本的APK
- 重要的文档

## 🔍 查找文件

如果需要查找历史文件：
1. 检查此目录的子目录
2. 查看 Git 历史记录
3. 查看 `DOCS-CLEANUP-SUMMARY.md`

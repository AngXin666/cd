# Design Document: Login Page Optimization

## Overview

登录页面视觉优化，主要调整透明度值以符合设计要求。

## 修改内容

### 1. 全屏适配（已实现）
- `position: fixed` 覆盖整个视口
- 背景图 `background-size: cover`

### 2. 背景图轮流显示（已实现）
- localStorage 存储索引 `login_bg_index`
- 循环公式：`(lastIndex + 1) % 3`

### 3. 透明度调整

| 组件 | 当前值 | 目标值 |
|------|--------|--------|
| 登录框背景 | `rgba(255, 255, 255, 0.5)` | `rgba(255, 255, 255, 0.5)` ✓ |
| 输入框背景 | `rgba(255, 255, 255, 0.45)` | `rgba(255, 255, 255, 0.45)` ✓ |
| 按钮样式 | 半透明 | 保持不变 ✓ |

### 4. 确认无毛玻璃效果
- 不使用 `backdrop-filter` 或 `blur`

## 验证方式

手动视觉验证：
1. 页面全屏显示
2. 每次进入页面背景图切换
3. 透明度效果正确

- 集成测试: `*.integration.test.ts`
- 端到端测试: `*.e2e.test.ts`

### 2. 测试结构
```typescript
describe('模块名', () => {
  describe('功能分组', () => {
    it('应该做什么', () => {
      // Arrange: 准备测试数据
      // Act: 执行测试操作
      // Assert: 验证结果
    })
  })
})
```

### 3. 测试注释
- 所有测试文件必须有文件头注释
- 复杂测试用例必须有注释说明

## 💡 测试最佳实践

1. **测试独立性**: 每个测试应该独立运行，不依赖其他测试
2. **测试可读性**: 使用描述性的测试名称，清晰表达测试意图
3. **测试覆盖**: 覆盖正常流程、边界条件、错误处理
4. **Mock 最小化**: 尽量使用真实数据，减少 Mock
5. **快速反馈**: 测试应该快速运行，避免过度依赖外部服务

# Implementation Plan: 用户管理功能测试（精简版）

## Overview

精简后的用户管理测试方案，聚焦核心功能验证。使用 pytest 进行单元测试，仅对最关键的业务逻辑使用属性测试。

## Tasks

- [x] 1. 修改车队长创建司机权限
  - 修改 `auth.py` 中的 `require_admin` 依赖，允许车队长创建司机
  - 修改 `routers/users.py` 中的 `create_user` 接口，车队长创建司机时自动分配到其管理的仓库
  - _Requirements: 1.4, 12.1_

- [x] 2. 修改禁用用户权限逻辑
  - 修改权限检查，禁用用户可登录查看但无法进行数据录入操作
  - 在打卡、计件等接口添加 `is_active` 检查
  - _Requirements: 8.1, 12.3_

- [x] 3. 编写权限矩阵单元测试
  - [x] 3.1 测试用户创建权限
    - 老板创建各角色用户
    - 调度创建车队长/司机（不能创建老板）
    - 车队长创建司机
    - 司机无法创建用户
    - _Requirements: 1.1-1.5_
  - [x] 3.2 测试用户更新权限
    - 老板更新任意用户
    - 调度更新车队长/司机
    - 车队长更新所辖仓库司机
    - _Requirements: 2.1-2.8_
  - [x] 3.3 测试用户删除权限
    - 老板删除用户（不能删除自己）
    - 调度删除车队长/司机
    - 车队长/司机无法删除用户
    - _Requirements: 3.1-3.7_

- [x] 4. 编写仓库分配单元测试
  - 测试仓库分配替换语义（新分配替换旧分配）
  - 测试车队长只能分配其管理的仓库
  - 测试分配后查询一致性
  - _Requirements: 5.1-5.8_

- [x] 5. 编写数据验证单元测试

  - 测试无效角色被拒绝
  - 测试必填字段验证不需要
  - 测试用户详情不泄露密码
  - _Requirements: 1.6-1.8, 4.6_

- [x] 6. Checkpoint - 运行所有测试
  - 确保所有测试通过，如有问题请询问用户

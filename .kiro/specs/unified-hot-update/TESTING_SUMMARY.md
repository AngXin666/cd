## 测试流程建议

### 开发阶段
1. 使用 **快速测试指南** 进行日常开发验证
2. 重点关注"最小测试集"
3. 确保核心功能正常

### 功能完成阶段
1. 使用 **测试执行清单** 进行系统测试
2. 完成所有测试项
3. 记录测试结果和问题

### 发布前阶段
1. 使用 **平台测试指南** 进行完整测试
2. 执行所有测试场景
3. 完成测试报告
4. 确认所有阻塞性问题已解决

## 测试优先级

### P0 - 必须测试（阻塞发布）
- ✅ 平台识别正确性
- ✅ 开发模式跳过更新
- ✅ 错误不导致崩溃
- ✅ 基本日志输出

### P1 - 重要测试（建议完成）
- ⚠️ 小程序更新流程
- ⚠️ Android 更新流程
- ⚠️ 强制更新和可选更新
- ⚠️ 错误处理和重试

### P2 - 可选测试（时间允许）
- 📝 边界条件测试
- 📝 性能测试
- 📝 兼容性测试

## 测试环境要求

### 微信小程序
- 微信开发者工具
- 微信公众平台账号
- 测试小程序 AppID

### Android APP
- Android 设备或模拟器（Android 5.0+）
- Android Studio 或 adb 工具
- Supabase 数据库访问权限
- 测试 APK 文件

### H5
- 现代浏览器（Chrome、Firefox、Safari）
- 本地开发服务器
- 网络连接

# 新页面开发规范

## 概述

本文档定义了在项目中创建新页面时必须遵循的开发规范，确保所有页面具有一致的结构和用户体验。

## 强制要求

### ⚠️ 必须包含 SafeAreaTop 组件

**所有新页面都必须在顶部包含 SafeAreaTop 组件**，以确保页面内容不会与系统状态栏重叠。

这是一个**硬性规则**，无例外！

## 页面开发流程

## 开发规范详解

### 1. SafeAreaTop 组件使用规范

#### 1.1 位置要求

- **必须**是页面容器的第一个子元素
- 如果页面有 TopNavBar，SafeAreaTop **必须**在 TopNavBar 之前
- **不能**放在滚动容器内部

```typescript
// ✅ 正确
<View className="page-container">
  <SafeAreaTop />
  <TopNavBar />
  <View className="content">内容</View>
</View>

// ❌ 错误：位置不对
<View className="page-container">
  <TopNavBar />
  <SafeAreaTop />  {/* 错误：应该在 TopNavBar 之前 */}
  <View className="content">内容</View>
</View>

// ❌ 错误：在滚动容器内
<View className="page-container">
  <ScrollView>
    <SafeAreaTop />  {/* 错误：会随内容滚动 */}
    <View className="content">内容</View>
  </ScrollView>
</View>
```

#### 1.2 背景色设置

- 默认使用透明背景（适用于大多数页面）
- 当页面有特定背景色时，设置 SafeAreaTop 的背景色与页面一致
- 使用变量或常量管理背景色，避免硬编码

```typescript
// ✅ 正确：背景色一致
const backgroundColor = '#F8FAFC'
<View style={{ background: backgroundColor }}>
  <SafeAreaTop backgroundColor={backgroundColor} />
</View>

// ⚠️ 不推荐：背景色不一致
<View style={{ background: '#F8FAFC' }}>
  <SafeAreaTop />  {/* 透明背景可能导致视觉不一致 */}
</View>
```

#### 1.3 导入语句

- 导入语句应放在文件顶部的导入区域
- 使用绝对路径导入（`@/components/SafeAreaTop`）

```typescript
// ✅ 正确
import { View } from '@tarojs/components'
import SafeAreaTop from '@/components/SafeAreaTop'
import TopNavBar from '@/components/TopNavBar'

// ❌ 错误：使用相对路径
import SafeAreaTop from '../../components/SafeAreaTop'
```

### 2. 页面结构规范

#### 2.1 基本结构

所有页面应遵循以下结构：

```typescript
<View className="page-container">
  {/* 1. 顶部安全区域（必须） */}
  <SafeAreaTop />
  
  {/* 2. 导航栏（可选） */}
  <TopNavBar />
  
  {/* 3. 页面内容 */}
  <View className="content">
    {/* 内容区域 */}
  </View>
  
  {/* 4. 固定元素（可选） */}
  <View className="fixed-elements">
    {/* 浮动按钮等 */}
  </View>
</View>
```

#### 2.2 样式类名规范

- 页面容器使用 `page-container` 类名
- 内容区域使用 `content` 类名
- 滚动区域使用 `scroll-content` 类名

```scss
// index.scss
.page-container {
  width: 100%;
  min-height: 100vh;
  background: #ffffff;
}

.content {
  padding: 20px;
}

.scroll-content {
  height: calc(100vh - 24px - 44px); // 减去 SafeAreaTop 和 TopNavBar 高度
}
```

### 3. 代码注释规范

#### 3.1 文件注释（必须）

每个页面文件开头必须添加文件说明：

```typescript
/**
 * 用户管理页面
 * 提供用户列表查看、添加、编辑、删除功能
 * @module pages/super-admin/user-management
 */
```

#### 3.2 组件注释（必须）

页面组件必须添加 JSDoc 注释：

```typescript
/**
 * 用户管理页面组件
 * 显示用户列表，支持搜索、筛选、添加、编辑、删除用户
 */
const UserManagement: React.FC = () => {
  // 组件实现
}
```

#### 3.3 关键逻辑注释（必须）

复杂逻辑和关键步骤必须添加注释：

```typescript
/**
 * 处理用户添加
 * @param userData - 用户数据
 */
const handleAddUser = async (userData: UserData) => {
  try {
    // 1. 验证用户数据
    if (!validateUserData(userData)) {
      showToast({ title: '数据验证失败', icon: 'error' })
      return
    }
    
    // 2. 调用 API 创建用户
    await UsersAPI.createUser(userData)
    
    // 3. 清除缓存并刷新列表
    clearCache()
    await refresh()
    
    // 4. 显示成功提示
    showToast({ title: '添加成功', icon: 'success' })
  } catch (error) {
    // 5. 错误处理
    console.error('添加用户失败:', error)
    showToast({ title: '添加失败', icon: 'error' })
  }
}
```

### 4. 性能优化规范

#### 4.1 使用缓存 Hooks

对于需要加载数据的页面，使用项目提供的缓存 Hooks：

```typescript
import { useUserListCache } from '@/hooks/useUserListCache'

const UserManagement: React.FC = () => {
  const { users, loading, refresh, clearCache } = useUserListCache()
  
  // 使用缓存数据
}
```

#### 4.2 避免不必要的渲染

使用 React.memo、useMemo、useCallback 优化性能：

```typescript
import { useMemo, useCallback } from 'react'

const UserManagement: React.FC = () => {
  // 使用 useMemo 缓存计算结果
  const filteredUsers = useMemo(() => {
    return users.filter(user => user.role === 'DRIVER')
  }, [users])
  
  // 使用 useCallback 缓存回调函数
  const handleDelete = useCallback((userId: string) => {
    // 删除逻辑
  }, [])
}
```

### 5. 错误处理规范

#### 5.1 加载状态处理

```typescript
const { data, loading, error } = useDataCache(...)

if (loading) {
  return <Loading />
}

if (error) {
  return <ErrorView message={error.message} />
}

return <DataView data={data} />
```

#### 5.2 异步操作错误处理

```typescript
const handleSubmit = async () => {
  try {
    await API.submitData(...)
    showToast({ title: '提交成功', icon: 'success' })
  } catch (error) {
    console.error('提交失败:', error)
    showToast({ title: '提交失败', icon: 'error' })
  }
}
```

## 常见错误

### 错误 1: 忘记添加 SafeAreaTop

```typescript
// ❌ 错误：缺少 SafeAreaTop
const MyPage: React.FC = () => {
  return (
    <View className="page-container">
      <TopNavBar />
      <View className="content">内容</View>
    </View>
  )
}

// ✅ 正确：包含 SafeAreaTop
const MyPage: React.FC = () => {
  return (
    <View className="page-container">
      <SafeAreaTop />
      <TopNavBar />
      <View className="content">内容</View>

}
```

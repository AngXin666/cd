# 🚀 Windows 编码配置快速开始

## 问题症状

如果你遇到以下任何问题，说明需要配置编码：

- ❌ PowerShell 或 CMD 中显示中文乱码
- ❌ Git 显示中文文件名为转义序列（如 `\344\270\255\346\226\207`）
- ❌ Node.js 脚本处理中文文件名失败
- ❌ Python 脚本输出中文乱码
- ❌ VSCode 打开文件显示乱码
- ❌ 脚本执行时报告编码错误

---

## ⚡ 一键配置（推荐）

### 步骤 1：运行配置脚本

在项目根目录打开 PowerShell，运行：

```powershell
.\scripts\setup-encoding.ps1
```

### 步骤 2：重启工具

配置完成后，重启以下工具使配置生效：

1. **重启 VSCode**
2. **重启 PowerShell**（或运行 `. $PROFILE` 立即生效）

### 步骤 3：验证配置

运行以下命令验证配置是否成功：

```powershell
# 检查代码页（应该显示 65001）
chcp

# 测试中文显示
Write-Host "你好，世界！"

# 测试 Git 中文显示
git status
```

**预期结果**：
- `chcp` 显示：`活动代码页: 65001`
- 中文正确显示，没有乱码
- Git 正确显示中文文件名

## 🔧 手动配置（可选）

如果一键配置失败，可以手动执行以下步骤：

### 1. 配置 Git

```powershell
.\scripts\setup-git-encoding.ps1
```

### 2. 配置 PowerShell Profile

```powershell
.\scripts\setup-powershell-profile.ps1
```

### 3. 检查 VSCode 配置

确保 `.vscode/settings.json` 包含以下配置：

```json
{
  "files.encoding": "utf8",
  "files.autoGuessEncoding": false,
  "files.eol": "\n"
}
```

### 4. 检查 .gitattributes

确保项目根目录有 `.gitattributes` 文件，内容包含：

```
* text=auto eol=lf
*.js text eol=lf
*.ts text eol=lf
```

## 🐛 常见问题

### Q1: PowerShell 仍然显示乱码

**解决方案**：

1. 确认 PowerShell Profile 已配置：
   ```powershell
   Test-Path $PROFILE
   Get-Content $PROFILE
   ```

2. 手动加载 Profile：
   ```powershell
   . $PROFILE
   ```

3. 或者重启 PowerShell

### Q2: Git 仍然显示转义序列

**解决方案**：

1. 检查 Git 配置：
   ```powershell
   git config --global core.quotepath
   ```
   应该显示 `false`

2. 如果不是 `false`，手动设置：
   ```powershell
   git config --global core.quotepath false
   ```

### Q3: VSCode 终端仍然乱码

**解决方案**：

1. 检查 VSCode 设置中的终端配置
2. 重启 VSCode
3. 在 VSCode 终端中运行 `chcp 65001`

### Q4: Node.js 脚本处理中文失败

**解决方案**：

1. 使用项目提供的编码工具：
   ```javascript
   const { readFileUTF8, writeFileUTF8 } = require('./scripts/encoding-utils');
   ```

2. 确保文件操作指定 UTF-8 编码：
   ```javascript
   fs.readFile(path, 'utf-8', callback);
   ```

### Q5: Python 脚本输出乱码

**解决方案**：

1. 在脚本开头添加编码声明：
   ```python
   # -*- coding: utf-8 -*-
   ```

2. 设置标准输出编码：
   ```python
   import sys
   import io
   sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
   ```

## 💡 最佳实践

### 1. 新建文件时

- 在 VSCode 中创建文件会自动使用 UTF-8 编码
- 检查状态栏确认编码为 `UTF-8`

### 2. 编写脚本时

**Node.js 脚本**：
```javascript
// 使用编码工具
const { readFileUTF8, writeFileUTF8 } = require('./scripts/encoding-utils');

// 或者显式指定编码
fs.readFile(path, 'utf-8', callback);
```

**PowerShell 脚本**：
```powershell
# 脚本开头添加
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
chcp 65001 > $null
```

**Python 脚本**：
```python
# -*- coding: utf-8 -*-
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```

### 3. Git 操作时

- 提交信息使用中文时，Git 会自动使用 UTF-8 编码
- 中文文件名会正确显示，不会转义

### 4. 团队协作时

- 确保所有团队成员都执行了编码配置
- 提交代码前检查文件编码
- 使用 `.editorconfig` 统一编辑器配置

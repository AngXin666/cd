## 📊 项目概览

### 基本信息

| 项目属性 | 值 |
|---------|-----|
| **项目名称** | 车队管家 (miaoda-taro-react-starter) |
| **当前版本** | 1.6.1 |
| **技术栈** | Taro 4.1.5 + React 18 + TypeScript + Supabase |
| **支持平台** | 微信小程序 / H5 / Android APP |
| **包管理器** | pnpm 10.17.1 |

### 项目定位

车队管家是一款专为物流车队打造的多端管理应用，提供完整的车队运营管理解决方案，包括：
- 多角色权限管理（老板/调度/车队长/司机）
- 考勤打卡与计件工资管理
- 请假/离职审批流程
- 车辆信息与租赁管理
- 实时通知系统

## 📱 功能模块

### 角色与页面分布

| 角色 | 页面数 | 主要功能 |
|------|--------|----------|
| **司机端** | 17 | 打卡、计件、请假、车辆管理、通知 |
| **车队长端** | 9 | 司机管理、审批、数据统计、仓库品类 |
| **老板端** | 22 | 用户管理、仓库管理、车辆管理、权限配置、全局统计 |
| **个人中心** | 7 | 设置、账号管理、密码修改、帮助 |
| **共享页面** | 5 | 通知模板、定时通知、自动提醒 |

### 核心功能模块

#### 1. 考勤管理
- 上班/下班打卡
- 地理位置验证
- 考勤统计报表
- 迟到/早退/缺勤状态

#### 2. 计件工资
- 多品类计件录入
- 单价配置（纯司机/带车司机）
- 上楼费/分拣费支持
- 日/月统计报表

#### 3. 请假/离职管理
- 请假申请与审批
- 离职申请与审批
- 多级审批流程
- 通知推送

#### 4. 车辆管理
- 车辆信息录入
- 行驶证 OCR 识别
- 车辆照片管理
- 审核流程（待审核/已通过/需补录）
- 租赁信息管理

#### 5. 通知系统
- 实时通知推送
- 通知分类（系统/审批/提醒）
- 已读/未读状态
- 批量通知

#### 6. 权限系统
- 四级角色（老板/调度/车队长/司机）
- 权限等级（完整控制/仅查看）
- 仓库级别权限分配
- RLS 数据隔离

## 🗄️ 数据库设计

### 核心表结构

| 表名 | 用途 | 主要字段 |
|------|------|----------|
| **users** | 用户信息 | id, name, phone, role, driver_type |
| **warehouses** | 仓库信息 | id, name, address, is_active |
| **warehouse_assignments** | 仓库分配 | user_id, warehouse_id, permission_level |
| **vehicles** | 车辆核心信息 | id, plate_number, driver_id, status |
| **vehicle_documents** | 车辆扩展信息 | vehicle_id, 照片字段, 租赁信息 |
| **driver_licenses** | 驾驶证信息 | driver_id, license_number, valid_until |
| **attendance** | 考勤记录 | user_id, work_date, clock_in/out_time |
| **piece_work_records** | 计件记录 | user_id, category_id, quantity, amount |
| **leave_applications** | 请假申请 | user_id, start_date, end_date, status |
| **resignation_applications** | 离职申请 | user_id, resignation_date, status |
| **notifications** | 通知消息 | recipient_id, title, content, is_read |

### 类型定义

项目定义了丰富的 TypeScript 类型（`src/db/types.ts`），包括：
- 用户相关：`User`, `UserWithRole`, `Profile`, `UserRole`
- 仓库相关：`Warehouse`, `WarehouseAssignment`, `PermissionLevel`
- 车辆相关：`Vehicle`, `VehicleDocument`, `VehicleWithDocuments`, `DriverLicense`
- 业务相关：`AttendanceRecord`, `PieceworkRecord`, `LeaveRequest`, `Notification`
